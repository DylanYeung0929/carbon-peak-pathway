# 中国碳达峰路径的驱动机制识别与多情景预测

基于国家级碳排放与宏观时序数据，构建「机制解释 — 预测比较 — 情景模拟」一体化分析框架：以扩展 STIRPAT 与 EKC 检验识别驱动机制，以滚动一步预测比较模型外推能力，再以多情景模拟推演 2035 年达峰路径，为减排政策提供量化依据。

## 问题背景

在全球「双碳」战略背景下，科学识别碳排放驱动因素并预测达峰路径是核心议题。碳排放受经济规模、产业结构、能源与技术等多因素交织影响，需要回答三个递进问题：① 人口、富裕度、能源强度、能源结构、产业结构、技术进步和治理投入对碳排放的方向与强度如何；② 在国家级小样本时序条件下，不同预测模型的外推能力是否存在稳定差异；③ 不同政策强度下，未来峰值水平与达峰路径将如何分化。

## 数据

- 2005—2022 年国家级观测数据（CEADs 省级表观碳排放清单按年汇总 + 国家统计局宏观指标口径匹配），2023—2024 年数据用于外推衔接与情景延展
- 核心变量：煤炭占比、人均 GDP、能源强度、产业结构、技术进步、治理投入等

## 方法与结果

**机制识别**：EKC 检验 + 扩展 STIRPAT + 中介效应分析。受小样本自由度约束，扩展 STIRPAT 中仅**煤炭占比**在 95% 置信水平下保持显著正向影响（弹性约 **3.3791**）；人均 GDP、能源强度等变量点估计多为正但置信区间较宽。

**预测比较**：滚动一步预测框架下，**AR2 模型外推最稳健**（RMSE = 1323.36，MAPE = 3.32%）；引入高维特征的多变量回归与复杂机器学习模型（XGBoost、随机森林）因样本量极小导致严重过拟合，误差急剧放大。

**多情景模拟**：设定基准、低碳、深度脱碳三类情景，到 2035 年碳排放分别约为 **39127.33 Mt、33013.06 Mt、27766.48 Mt**；历史观测峰值约 40358.26 Mt（2022 年），三类政策情景峰值均低于该历史高点。
